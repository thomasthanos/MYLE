## 🪄 Windows Optimization

MYLE now handles Windows tweaks and app removal directly, replacing the previous external debloat tools.

- **Choose first, apply together.** Debloat checkboxes select the next run. **Apply selected** shows the changes and apps for review, creates a restore point, then applies them.
- **Recommended choices respect your preferences.** First-use defaults include available safe tweaks; saved selections are kept. Caution changes such as removing Edge remain explicit choices with an extra confirmation.
- **Categories in a responsive grid:** three columns in wide windows, two at medium widths and one in smaller windows. Debloat, Tweaks, Start Menu and Apps share consistent controls.
- **Clear state badges:** Applied, Partly applied, Not applied and Unavailable. Selection is shown separately from what Windows has actually applied.
- **Search and filters keep your choices.** Presets work across the full eligible list, with total selection counts visible.
- **Individual Apply, Undo and Turn off actions.** Undo MYLE changes restores only tweaks for which MYLE has kept an undo record.
- **App removal stays reviewable.** Recommended badges come from the app catalog, Xbox dependencies are called out, and removed apps offer **Get it again**.

## 📌 Start Menu

- Change alignment, layout and the All Apps view.
- Control recommendations, recent items and account notifications.
- Choose quick folders with **Essential / All / None** presets.
- Select pinned apps and apply them together. Choices survive switching tabs; clearing pins and restoring the previous layout remain separate actions.
- Unsupported Windows builds show an explanation and disabled controls. Failed saves keep the previous displayed setting and release the busy state.

## 🎮 Game Saves

- Backup location, automatic backup and installation folders have clearer settings and controls.
- Scheduled backups can show a completion notice, including failures that need attention.
- Folder overlap checks help keep backups outside locations that could be scanned or cleaned.
- Concurrent settings updates preserve changes saved while a picker, scan or scheduled-task operation was pending.
- Game-title matching is more consistent, and custom-game preferences are retained when scan results are combined.
- Backup rows and detection perform fewer unnecessary scans.

## 🔐 Password Manager and account

- Website icons are fetched only from public addresses, including redirected requests.
- Browser site matching uses the Public Suffix List consistently with the app.
- Recovery now shows password strength and requires an acceptable new master password.
- Linking an executable avoids duplicate app chips; copy feedback appears only after a successful copy.
- Concurrent account requests share one token refresh, and a late rejection of an old token does not clear a newly signed-in session.
- Background loopback requests cannot prematurely finish sign-in, and a changed avatar URL can load after an earlier image failed.

## 🛠️ Reliability across the app

- The cleaner reserves the install/update job gate for the duration of cleaning and reports skipped files more accurately after an administrator retry.
- Cleaner traversal handles links without deleting their targets and keeps deletion within allowed locations.
- Downloads reject HTML error pages even after retrying a ranged transfer.
- Maintenance jobs use separate temporary folders; elevated pipe clients are checked against the expected helper process.
- WebView2 setup is verified as signed by Microsoft before it runs and held against replacement during verification.
- Auto-Logon releases its busy state when an operation is abandoned.
- Startup shortcuts use the Windows shell directly, including paths with Greek characters.
- Installer version comparisons correctly handle prereleases and ignore build metadata.
- Simpler npm commands, script tests in CI, updated documentation and public download links. The legacy installer URL remains available.

## 📦 Install or update

Download **MYLE.exe** from this release or use the download button above. Existing installations can use MYLE's built-in updater.

**Requirements:** Windows 10 or 11, x64. Start Menu customization requires a supported Windows 11 build. The setup installs Microsoft's WebView2 Runtime if it is missing.
