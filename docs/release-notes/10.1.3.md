# MYLE 10.1.3

- **Auto Clicker & Macros.** A new page clicks for you: at the cursor, or through a sequence of saved screen points, each with its own button (left, right or middle), single or double clicks and timing. Pick a point by clicking anywhere on screen, run a set number of times or until you stop, and start or stop with F6 from anywhere while MYLE runs. A short countdown leaves time to move away, and profiles are saved for next time.
- **A faster start.** The main window opens about half a second sooner: the splash appears first, the window opens as soon as it is ready, and winget, pictures and online checks wait until it is on screen.
- **A lighter app in the background.** Project Backups no longer re-checks a project every few seconds while something keeps writing to it, so MYLE uses far less CPU at rest. While the window is minimized or in the tray, it keeps less in memory.
- **Smarter Software Health leftovers.** Folders in AppData and ProgramData that nothing on the PC uses are now found: MYLE checks installed programs, running and recently run apps (portable ones too), services, Store apps, shortcuts, command-line tools and games' save folders, never a fixed list of names. Each folder shows what it holds and how long it has been untouched; empty ones come selected, everything else waits for your review and goes to the Recycle Bin.
- **Clear permissions and errors.** Folders only an administrator can move are marked before you clean, and a failed move says why (administrator needed, open in another program, no longer there) instead of a code.
- **Software hibernation opens again.** A program running as several processes appears once, with its memory and CPU added up, and the App controls list no longer stops responding when it is opened.

This Windows release includes the MYLE installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
