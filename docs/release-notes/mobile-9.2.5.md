# MYLE Passwords 9.2.5

### ✨ Sign in without leaving the app
- **iPhone:** Discord and Google open in iOS's own sign-in sheet over the app, and close by themselves when you are signed in. If you are already signed in to them in Safari, it takes one tap.
- **Android:** the sign-in page opens over the app (a Chrome tab) and comes back by itself; closing it cancels the sign-in.

### 🔄 Updates that just work (Android)
- **Update** downloads the new version inside the app, with its progress, and opens Android's installer: no browser, nothing left in Downloads.
- Each version has its own download address, so an update can no longer install the previous APK again (the reason the same update kept coming back).
- The first time, Android asks to allow MYLE Passwords to install updates: allow it, come back, and the installer opens by itself.
- An update already downloaded is not downloaded again.

### 🎨 Icons and screen
- **iPhone:** the app icon follows the Home Screen's look: light, dark or tinted (iOS 18+).
- **Android:** the app no longer runs under the status bar, the navigation bar or the camera cutout, and the keyboard no longer covers what you type.

### 🐛 Fixes
- Face ID / fingerprint is offered once after you open the vault with your master password, not every time.
