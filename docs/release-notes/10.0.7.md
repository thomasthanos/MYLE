# MYLE 10.0.7

- **Firefox local extension installation.** MYLE now copies the Firefox build into its local extension folder, repairs missing or older Firefox files, and detects when the loaded Firefox copy needs reloading. Settings and browser setup offer the local installation directly; Firefox uses the bundled copy without a Firefox store download. Unsigned temporary add-ons must be loaded again after restarting Firefox.
- **Chromium browser support.** The native messaging host now also recognizes Chromium itself, alongside Chrome, Edge, Brave, Vivaldi, Opera, Arc and Thorium. Both extension builds are version 10.0.7.
- **Android passwords and 2FA.** Removed Android Autofill and Credential Manager providers, their native services and activities, JNI bridge, settings, resources and dependencies. Passwords remain available for manual viewing and copying, and saved TOTP codes still display with their countdown and copy action. QR scanning, account sync and biometric vault unlock remain available.
- **Preserve synced passkeys.** Android no longer shows passkey controls. Existing passkeys remain in the encrypted vault for desktop and iOS use; Android prevents deleting a login containing a passkey and keeps passkeys when deleting all passwords. Manage those passkeys in MYLE on your PC.

This release includes the Windows installer, Android APK, iOS IPA and Chromium/Firefox extension packages. The Firefox extension is distributed for local installation.
