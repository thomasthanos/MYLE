# MYLE 12.0.1

### New
- **A new uninstall window:** uninstalling MYLE opens its own window, where you choose whether your settings and data go too.
- **Setup messages in MYLE's own style:** "Setup is already running" and "MYLE is not installed" now appear in a MYLE window rather than a plain Windows message box.
- **Sign-in finishes on MYLE's website:** after you sign in, the browser tab shows a page on MYLE's site saying whether it worked. The one-time sign-in code never reaches the site.
- **GitHub Releases:** an AI key you save is kept with your MYLE account and restored on your other PCs when you sign in.
- **Ready for MYLE's own publisher name:** from the next release on, the setup can show **ThomasT** as MYLE's publisher instead of "unknown". It asks you first, needs no administrator rights, and uninstalling MYLE takes it back.

### Improved
- **AI keys explained:** under each key field, GitHub Releases says where that provider's keys come from and how they start. When a provider turns a key down because it belongs to another service (a Grok site's key in the Groq field, say), the message says so, and Gemini's "API key not valid" now reads as a rejected key.
- **Project Backups:** with "Follow .gitignore" on, what the repository's own exclude list (`.git/info/exclude`) ignores is left out too.
- **Uninstalling with "remove data"** also removes the Password Manager's Windows Hello key.
- **A refreshed app icon**, notices placed better on screen, and windows centred correctly on every monitor.
