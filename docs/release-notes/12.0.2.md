# MYLE 12.0.2

### New
- **MYLE has a publisher name: ThomasT.** MYLE is now signed with its own certificate. Right after this update, "What's new" offers once to show **ThomasT** as MYLE's publisher in Windows instead of "unknown"; the same button is in **Settings › About**, and a new install offers it on the setup's last page. Windows asks you to confirm, no administrator rights are needed, and uninstalling MYLE takes it back.
- **Steam Automation:** a new sign-in page when Steam isn't connected yet.

### Fixed
- **Steam no longer asks you to sign in again for nothing.** When Steam turns a request down, MYLE first renews the sign-in out of sight, as the Sign in button would, and tries again. It asks you to sign in only when Steam has really ended the session.
- **Install Apps › Updates:** the lines winget prints under its list no longer show up as an update.
- **Signing in to your MYLE account** leaves the browser on the page that confirms it.
