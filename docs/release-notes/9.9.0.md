## 🎉 What's new window

- It opens once, on the first start after an update. It doesn't open on a fresh install.
- The notes come from the GitHub release. If GitHub can't be reached, MYLE shows the notes it ships with, or a link to the release.
- Skipped a few updates? Every version since the one you last saw is listed, newest first.
- Open it again any time from **Settings → About → What's new**.
- For safety, links open in your browser and nothing in the notes can run.

## 🧩 GitHub Releases: Combine

- **Combine** merges the notes into the newest release you picked. It then deletes the other releases and their tags, both on GitHub and on your PC.
- Before anything happens, a confirmation lists every release and tag that will go, and which release gets the notes.
- Nothing is deleted unless the combined release saved and its notes are confirmed on GitHub.
- The release that keeps the notes never loses its tag. A tag that another release (a draft, say) still uses is kept too, and MYLE tells you why.
- If something can't be deleted, MYLE lists what was left behind, with **Try again**.
- Deleting releases now finds them however many the repository has. A tag that is already gone no longer counts as an error.

## 🛠️ Fixes

- **Release:** the checks now also look for the tag on GitHub, not only on your PC. Before, a tag left on GitHub (a failed release, another PC) stopped the release after its commit had already been pushed.
- **Release:** a tag left on your PC by an earlier try is only pushed if it is on the release commit. A failed tag push no longer deletes a tag that was there before.
- **Release:** finishing a draft release finds it even when there are more than 50 newer releases.
- **Release:** a notes file picked with Windows backslashes is no longer committed twice.
- **Build:** a build now ends when its command does, even if a helper it started keeps running (MSVC's `mspdbsrv`, a daemon). Before, the page could stay on **Building** forever.
- **System Cleaner:** without the administrator pass, the space Windows kept in its own folders is now counted under "still in use". Before, it was left out.
- **Project Backups:** the summary now says **in latest backups** (only each project's newest zip is counted). Failed backups are grouped under **Did not finish**. A long run shows one toast instead of one per project. The health colours on the project icons are back.
