# MYLE 9.16.1

Spicetify updates that finish correctly, accurate installed status, and a refreshed dark theme inspired by Discord.

## Spotify & Spicetify

- Updating an already customized Spotify restores its existing backup before rebuilding and applying it with the new CLI. A fresh Spotify update keeps its new stock packages instead of restoring an older backup.
- The Hub compares installed Spicetify and Marketplace versions with the latest verified stable releases. Current installations show **Up to date** instead of offering the same update again.
- Updating one component preserves a newer version of the other component instead of downgrading it to the selected stable release.
- Marketplace versions are recorded with the verified installation and roll back with its files if setup fails. External changes invalidate that version record.
- Older Marketplace installations with no version record show **Installed**. **Repair / reinstall** records the verified release; unavailable release checks remain retryable with **Check again**.

## Dark theme & controls

- Matte dark navigation, clearer layered surfaces, and blurple primary actions inspired by Discord.
- More consistent buttons, inputs, selected chips, disabled states, and reduced-motion behavior.
- The Install Apps selection bar has an opaque background in the dark theme.

## Downloads

- **Windows:** download **MYLE.exe** or update from MYLE.
- Browser extension 1.5.1 and MYLE Passwords 9.3.0 are unchanged.
