## 🪄 Windows Optimization

- **Quick setup:** three profiles, each showing how many settings and apps it would change on this PC. **Light** is privacy and promoted apps only; **Recommended** adds what nearly everyone is better off with; **Maximum** also removes every promoted app, Phone Link, Teams and Spotify included. Edge, personal preferences (dark mode, the taskbar on the left) and the apps most people use are never in a profile.
- **Nothing changes while you choose.** Profiles, switches and app ticks only record choices. The bar below the tabs counts them; **Review & apply** lists them, lets you leave any out, then makes one restore point and applies them together.
- **One Settings list:** every setting on one line with a switch, in folding groups, with what it does and what you might miss a hover away.
- **Apps say what they are**, and a **Keep?** tag explains why you might keep one (Calculator, Photos, Snipping Tool, the Xbox apps, Phone Link). New: Paint 3D, Game Assist, the old Xbox Game Overlay, the Cross Device host, WhatsApp, Messenger and Dolby Access.
- **Windows features:** Steps Recorder, Math Input Panel, WordPad, XPS Viewer, Windows Media Player Legacy, PowerShell ISE, Internet Explorer mode and Fax and Scan can be removed, and added back from Windows Update.
- About half the height for rows, cards and gaps, so far more fits without scrolling.

## 🎮 Game Saves

- **Covers** from Steam for games with a Steam id in the save database, newer games included. Steam's cache on this PC comes first; the rest can come from Steam (**More → Covers from Steam** turns that off).
- **Back up what's new** backs up every game that needs its first backup or has new progress; its arrow does only one of the two.
- Status filters with counts, a single **Select all** checkbox, and a backup overview above the list.
- Compact rows: size, last save and last backup beside the name, about half as tall.

## 🛠️ Across the app

- Pages get their data and pictures ready while the splash shows, with no scans or downloads started for you.
- MYLE's own right-click menu (Copy, Cut, Paste, Select all as the field allows), never offering Copy on the vault's secret fields. The WebView menu and developer tools are off in releases.
- A clearer vault recovery, and tooltips that no longer interfere with page updates.

## 📦 Install or update

Download **MYLE.exe** from this release or use the download button above. Existing installations can use MYLE's built-in updater.

**Requirements:** Windows 10 or 11, x64. Start Menu customization requires a supported Windows 11 build. The setup installs Microsoft's WebView2 Runtime if it is missing.
