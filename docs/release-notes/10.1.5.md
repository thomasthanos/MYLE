# MYLE 10.1.5

- **Unified Auto Clicker & Macros UI.** Overhauled the Auto Clicker layout into a cohesive, user-friendly workspace. Simple Clicker now features an all-in-one studio card unifying timing, quick presets, mouse button options, click repeat limits, and a large tactile start action without fragmented side panels or dead space.
- **Enhanced Multi-Point Sequence flow.** Multi-point coordinate sequencing features a dedicated top control bar with loop repetitions, live status monitoring, and responsive grid tiling for sequence points.
- **Elevated profile management.** Profile selection, creation, renaming, and deletion now live in a unified top toolbar with real-time save status.
- **Robust debloat helper policy testing.** Strengthened debloat helper unit tests across clean Windows environments and automated CI runners.

This Windows release includes the MYLE installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
