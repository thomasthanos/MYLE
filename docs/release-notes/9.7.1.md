### New  
- Added a smooth **ProgressBar** component for visual feedback during cleaning operations.  
- Introduced **ProjectRow** and **StatTile** components to give clearer project‑backup overviews.  
- New health status badges for projects (e.g., “missing”, “failed”, “stale”, “ok”).  
- Backup page now shows a cloud‑off icon for unavailable backups.  

### Improved  
- **Backup UI**: streamlined layout, clearer icons, and better grouping of project statistics.  
- **System Cleaner UI**: displays both freed space and space still in use, with real‑time progress updates.  
- Cleaner now tracks and shows the total size of files it could not delete (`skipped_bytes`), giving users a more accurate “still in use” figure.  
- Cleaner summary now includes counts of skipped files and their byte size, plus admin‑retry statistics.  
- Added visual preview harness support (dev only) via `.preview/`.  

### Fixed  
- Corrected display of backup status when cloud sync is unavailable.  
- Fixed minor UI glitches in the cleaner cards when showing “checking” state.  
- Resolved issues where the cleaner’s progress bar would disappear before the operation completed.
