# MYLE 10.1.0

- **Clearer SFC and DISM progress.** Repeated percentage updates now replace the previous progress line and appear in a progress bar. Diagnostic messages stay readable instead of being buried under hundreds of repeated lines.
- **Check Disk through Windows Storage.** The system drive is scanned online with administrator approval, including on systems where Windows refuses to launch chkdsk.exe. Scan findings and failures are reported accurately. The scan does not schedule offline repairs or a restart.
- **Shortcuts and icons after updates.** Setup remembers Desktop, Start menu and Startup choices, restores missing selected shortcuts, and preserves explicit opt-outs. A stable MYLE icon and consistent app identity repair shortcuts and existing taskbar links after updates. The Start menu option registers MYLE in All apps; pinning to Start's pinned section remains a Windows action.
- **Optional taskbar pinning.** When selected in interactive setup, MYLE requests Windows confirmation after its window opens on supported Windows versions. Declined requests can be retried or dismissed. Older Windows versions show manual instructions, and ordinary launches and automatic updates do not reopen the confirmation dialog.

This Windows release includes the MYLE installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
