### New  
- Bundled site icons added for popular services (Epic Games, Samsung, Sony, etc.) so passwords load faster and work even when sites block background requests.  
- Icon revision tracking introduced; missed icons will be retried after an app upgrade.  
- New API to clear the app’s clipboard and invalidate scheduled clears, improving security after copying passwords.  

### Improved  
- Password vault now supports clearing the local device copy without affecting cloud data or creating tombstones.  
- Logout now performs a scoped global sign‑out for better session handling.  
- Sync status messages updated for clearer mobile vs. desktop experience.  
- Various UI refinements in password manager pages (entry view layout, totp code button styling, vault view scrolling).  

### Fixed  
- Fixed a bug where leftover private files could remain after account removal.  
- Resolved an issue where the clipboard could retain copies after the app cleared it.  
- Corrected size metadata for the latest iOS build in the store manifest.
