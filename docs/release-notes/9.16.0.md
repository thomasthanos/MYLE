## 💾 Project Backups

- Checked when the tab opens, every 5 minutes, and a few seconds after files change in a project folder (a folder watcher; build output, `node_modules` and `.git` are ignored).
- A file is new or deleted by its name; modified when its size differs, or when it was changed after the backup and its content (CRC-32) differs. Only those files are read. A project whose files did not move is not checked again.
- **Changes detected · N** opens the list of files (+ new, ~ modified, − deleted). The refresh button next to the toolbar checks everything now.
- **Back up changed (N)** backs up only those projects, with a new zip each, as before.

## ⚙️ Settings

- The page, its header and the search sit in a centred frame up to 1240 px wide.
- Two columns fill it: Account & sync, Startup & tray and About on the left; Appearance and Updates on the right. One column below 1000 px.

## 🧩 Browser extension 1.5.1

- The extension now tells MYLE its version.
- MYLE keeps its own copy for "Load unpacked" in its app data folder. **Open** in Browser filling makes or refreshes it, and after every MYLE update it is refreshed at start.
- When an unpacked copy is older than the one MYLE carries, Settings and Browser filling show **Local extension update available** with **Update Local Extension**. Then press Reload on the browser's extensions page.
