# MYLE 10.1.4

- **Refined Software Health UI & actions.** Finding cards feature clean vertical alignment, balanced spacing, and thematic category badges. Expandable details include direct "Copy path" and "Open in Explorer" actions, alongside dedicated failure callouts with clear explanations.
- **Reliable policy management.** System and user policies now apply cleanly through the elevated administrator helper, ensuring smooth changes across Windows settings.
- **Browser integration improvements.** Browser extensions and autofill communication target the installed application reliably.
- **Hardened async workflows & responsive UI.** Lazy-loaded pages and streamlined asynchronous flows keep navigation quick and resource usage minimal.
- **Tactile control styling.** Interactive buttons, toggles and sidebar links have improved tactile feedback and consistent spacing.

This Windows release includes the MYLE installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
