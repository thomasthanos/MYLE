# MYLE 12.0.3

### New
- **ThomasT in administrator prompts too:** once you trust ThomasT, **Settings › About** offers **Trust for every account**. Windows' administrator prompt only reads what every account on the PC trusts, so this is what makes it name ThomasT as MYLE's publisher. It asks for administrator rights once, and uninstalling MYLE takes it back the same way.

### Fixed
- **Dialogs stay inside MYLE's window:** the dark backdrop behind a dialog ("What's new", confirmations and the rest) no longer spills over the edge around the window, where its shadow is drawn.
- **Windows' question opens in front:** when you trust ThomasT, or the uninstaller takes it back, Windows' question no longer opens behind MYLE.
