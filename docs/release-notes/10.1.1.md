# MYLE 10.1.1

- **Disk Analyzer.** Find what fills a drive or folder with a treemap, folder tree, largest files and file types. A single drive picker shows capacity, free space and the selected scan target. The results offer clearer labels, sorting and size filters, with protected paths checked before anything goes to the Recycle Bin.
- **Faster NTFS scans.** Fast mode reads the drive's file table after Windows administrator approval. Normal mode scans folders without elevation; a declined or unavailable fast scan falls back to the folder scan. Size on disk accounts for allocated data runs.
- **Cloud storage controls.** Google Drive, MEGA, Dropbox and OneDrive have their own buttons in Disk Analyzer. Compatible Windows OneDrive and Dropbox folders can receive online-only requests for verified, fully uploaded files, with progress and a Stop control. Pending uploads, unverified files and unsafe links are left unchanged. The cloud app completes any space release; MYLE reports requests rather than claiming bytes have already been freed.
- **Provider-specific guidance.** Google Drive's button opens its folder and explains streaming, offline availability and cache management. MEGA's button explains normal sync and the separate MEGAcmd on-demand mount. These buttons do not automatically convert files or delete provider caches.
- **Backup history after reinstall.** Game Saves and Project Backups recover existing backup history from the selected backup location instead of depending only on settings stored on this PC. Game-save history is scoped to its backup folder so switching locations does not reuse another location's cached status.
- **Clearer taskbar pin guidance.** When Windows blocks pin confirmation because its Apps notifications are disabled, MYLE explains the setting and offers a button to open notification settings. Other refusals keep manual pinning instructions and an explicit retry instead of reporting success.

This Windows release includes the MYLE installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
