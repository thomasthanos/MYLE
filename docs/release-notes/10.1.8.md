# MYLE 10.1.8

- **Project relocation in Project Backups.** Scan drives or a folder for candidate projects, review suggested matches from folder names, Git remotes and package metadata, or replace a path prefix in bulk. Updating source paths preserves project IDs, backup history and exclusions; it does not move your files.
- **Fixed the relocation dialog lifecycle.** The full backdrop now uses the shared Svelte portal attachment, with the dialog's keyboard focus handler attached and cleaned up correctly when it closes.
- **Restored Windows release checks.** Fixed the Svelte/TypeScript errors that stopped 10.1.7 before its Windows installer could be published.

This release includes the Windows installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
