# MYLE 10.0.6

- **Fix unlocking MYLE on Android.** MYLE no longer offers its own autofill prompt for its master password or other vault fields. This prevents the misleading website/app authorization error when selecting “Unlock MYLE” inside MYLE itself.
- **Phone layouts.** Search and all three toolbar actions fit narrow screens. Password-generator and More menus fit the available width. The welcome page scrolls on short screens; its privacy information remains reachable.
- **Account and filling settings.** Added an explicit close button, keyboard focus containment, wrapping account details and settings, safe-area spacing, and scrollable content. Older Android versions show the Android 14+ passkey requirement directly.
- **Native verification screens.** Improved spacing and button readability. Failed autofill identity checks offer a retry that repeats the same website/app validation. Removed expensive full-screen backdrop blur and repeated panel entrance animations on mobile.

The Android Credential Manager provider requires Android 14 or later. On Android 11, passwords and saved TOTP codes use Android Autofill. Fingerprint availability depends on the device's enrolled strong biometric. Physical Samsung A22 behavior still needs verification on the phone; browser layout checks and native tests do not replace device testing.
