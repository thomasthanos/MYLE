### New
- **Delete all passwords** (Password Manager › ⋯ menu, on Windows and in MYLE Passwords on phones):
  - Asks for your master password and for DELETE to be typed, and offers a backup first (an encrypted backup on Windows, the Apple Passwords export on iPhone).
  - Logins with a passkey are kept with the passkey, and only their password is removed. **Also delete passkeys** is an option that is off by default and not recommended: passkeys cannot be imported back.
  - Each deletion is synced to your account as a sealed deletion record, so other devices remove the same entries and nothing comes back. The result shows how many were deleted and kept, and any sync error.
- **Imports re-attach passwords:** importing a CSV or a backup later puts each password back on the login that kept its passkey (the same site, as in `accounts.google.com` and `google.com`, and the same user name) instead of making a second entry.
- **Export for Apple Passwords (MYLE Passwords on iPhone):** makes a CSV in the layout Apple Passwords imports (Title, URL, Username, Password, Notes, OTPAuth) and opens the share sheet. Save it to Files, then import it in the Passwords app. The file is unencrypted, so delete it after the import. The app's own copy is deleted when the sheet closes. Passkeys are not included.
