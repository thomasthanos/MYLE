## 🚀 Release Hub

- **Merge first:** a list of the remote's branches (not main, not the current one), fetched when the tab opens; "None" by default. The merge is a merge commit pushed with the release.
- **Build:** the choice goes into the tag's message as `Build: windows` or `Build: full`. MYLE's own workflows read it: a Windows-only release skips the phone apps. Other projects' workflows can read the same line.
- **Monitoring:** the run, its jobs and the step running now are followed live, as before. New: when a job fails, even while others still run, its failed step, the errors GitHub reported and the last 40 lines of its log are shown under the steps.
