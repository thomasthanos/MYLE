## 🧹 MYLE's own downloads

- What MYLE downloads to install apps (Install Apps, Creative Suite) and Spotify Hub's working files are removed when MYLE closes.
- If MYLE was closed by a crash, or a file was still in use, it goes on the next start.
- Only MYLE's own folders are touched: never your files.

## 📥 System Cleaner: Downloads folder

- **Off until you turn it on**, on its own card under the categories.
- Finds your real Downloads folder through Windows, even if you moved it.
- **Keeps** documents (PDF, Word, Excel, PowerPoint, OpenDocument, text, RTF, CSV, Markdown, e-books and similar) and anything changed or created in the last 7 days. A folder goes only if nothing in it is kept. Links and junctions are never followed.
- **Show what would go** lists every item with its size and date. Untick what you want to keep.
- **Delete permanently** asks first, and says clearly that the files do not go to the Recycle Bin and cannot be restored. Files in use are skipped and left in place.

## ⚙️ Settings

- No more tabs: Account & sync, Appearance, Startup & tray, Updates and About are all on one page again.
- Small section headings, denser rows and two columns when the window is wide, so it all fits with little scrolling. Search still filters it.
