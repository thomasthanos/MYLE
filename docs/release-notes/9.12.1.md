## ✨ Highlights

| | What's new |
|---|---|
| 🔐 **No request missed** | A site that asks for a passkey as soon as its page opens (as Google's "Use your passkey to verify it's you" does) is now asked again once MYLE is ready, instead of going straight to Windows Security. |
| 💬 **Says why** | When MYLE has a passkey for the site but the site asks only for others, MYLE tells you, instead of quietly handing over to Windows. |
| 🐞 **Debug log** | A switch in the extension's popup writes every passkey step to the page's console, to send when a sign-in still fails. |

## 🔐 Passkeys

- **Early requests:** the part of the extension that shows MYLE's prompt starts once a page has loaded. A request made before that was lost, and the browser's own window (Windows Hello, Windows Security) took over. Such a request now waits and goes to MYLE as soon as it is ready.
- **Firmer hold on the page:** MYLE now answers however a site calls for a passkey: through `navigator.credentials` itself, a copied or bound function, or a frame of the same page. Its functions look like the browser's own to a site that checks, as other password managers' do.
- **This PC's authenticator:** a site that asks whether this PC can sign in with a passkey hears yes, so it offers the passkey step instead of hiding it.
- **"did not ask for MYLE's passkey":** a site's sign-in can list the passkeys it knows for the account. When MYLE's is not on that list (for example if saving it on the site did not finish), MYLE says so and offers **Another device**. Add the passkey again in the site's security settings to use MYLE's.
- Works the same in Microsoft Edge, Chrome, Brave and Firefox: MYLE's prompt comes before the browser's own window.

## 🧩 Browser extension (1.4.1)

- The popup shows the extension's version at the bottom, so you can check which one the browser has loaded.
- **Debug log** switch next to it. Turn it on, reload the page, and open the console (F12 → Console): each step shows as **[MYLE passkeys]**. It never writes passwords, keys or the site's challenge.
