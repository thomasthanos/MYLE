# MYLE 10.1.2

- **A clearer Disk Analyzer.** Drive cards collapse behind Change drive after a scan, leaving more room for the results. The map keeps its height and the page scrolls in shorter windows so the legend stays accessible. Folder outlines use a small set of muted colours, with clearer labels and more visible small blocks.
- **An explicit option for large items.** When Windows cannot put an item in the Recycle Bin, MYLE shows the reason next to its path and offers Delete permanently. This is a separate action with another confirmation showing the names and data size, including online-only files. The normal Recycle Bin action never falls back automatically, and both actions keep the same protected-path checks.
- **Deletion progress inside folders.** The progress bar follows Windows' work estimates within the current folder, with an animated indicator while Windows is preparing. The earlier Recycle Bin failure message steps aside during the retry.
- **Cloud storage controls.** A single online-only action covers the supported cloud folders found on this PC. Cloud-folder detection includes additional Windows sync roots, and the Google Drive flow has improved handling of offline availability and its storage window. Availability still depends on the cloud client and sync status.
- **GitHub project folders remembered.** GitHub Releases project paths are saved with account settings and restored after signing in again. Restoring the list preserves local project configuration and waits while a release operation is busy.
- **Cleaner Project Backups.** Empty status filters stay out of the way, and backup progress has its own row so controls and progress no longer overlap.

This Windows release includes the MYLE installer and Chromium/Firefox extension packages. MYLE Passwords for Android and iOS remains on its existing release.
