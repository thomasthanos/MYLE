# MYLE 11.0.0

### New
- **Steam Game Helper:** a new page with what's worth playing on Steam. Everything free right now, free weekends, the best-reviewed deals, free-to-play games and twelve picks chosen each week, filtered by online co-op, single-player or story.
- **Free games come to you:** once you have opened Steam Game Helper, a small notice in the corner of the screen tells you when something new becomes free.
- **Get it from the card:** free weekends and free-to-play games open Steam's own install window straight from their card.

### Improved
- **Steam Game Helper opens at once:** it shows the lists it saved last time and refreshes them in the background, so you don't wait on Steam each time you open it.
- **A tidier data folder:** MYLE's internal files now live in a hidden folder and its Steam data in one place, so the folder is no longer cluttered. Your data moves over by itself the next time MYLE starts.
- **Corner notices** now use MYLE's own tooltips, like the rest of the app.
