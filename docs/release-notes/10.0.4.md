# MYLE 10.0.4

- **Passkey name assistance.** After you choose to create a passkey in MYLE, the browser extension fills `MYLE` in a supported naming dialog for that new credential. Confirm the website's Save button yourself. Naming dialogs must explicitly describe a newly created passkey or carry its matching credential ID; unrelated editors and names you type are left alone.
- The helper works on the current page for two minutes, including supported web components. It does not change credential IDs, account names, keys or WebAuthn responses, and requires no additional extension permissions.
- Websites control which naming fields they offer and which provider names they display. This does not force a universal provider name or rename existing passkeys. Live testing of Google Account's naming interface is pending account verification; no Google compatibility claim is made for this helper.
- Includes updated Chrome/Edge/Brave/Vivaldi and Firefox extension ZIPs.
