## 🔑 Passkeys

- When a site offers to create a passkey, MYLE asks **Save in MYLE?**; when it asks for one, MYLE lists yours. **Another device** leaves it to Windows Hello, your phone or a security key, as before.
- A passkey goes with the login of that account on the site, is sealed in your vault and syncs to your other PCs.
- MYLE signs only for the site you are on, only after your click, and with Windows Hello when the site asks to confirm it is you.
- Sign-in forms that suggest passkeys as you type show MYLE's in its menu on the user name field.
- Each login lists its passkeys, each with Delete.

## 🛡️ 2FA codes

- Add a site's 2FA key to a login: paste the key or its link, snip the QR code with Win+Shift+S and paste it, or open a picture of it.
- The login shows the 6-digit code with how long it holds, and copies it.
- In the browser, click the site's code field: MYLE fills the code, into one field or a row of boxes.
- The key stays in the app, sealed with the login like its password.

## 💾 Offers to save

- A login you type into a site is offered for saving on the next page, and also on sites that sign you in without leaving the page.
- With the vault locked, **Save** opens MYLE and saves the login as soon as you unlock it (or says it was already there).
- Turning on 2FA on a site: MYLE spots the setup key and offers to keep it with that site's login, so it fills the codes from then on. A QR code alone is read from the toolbar button's **2FA from a QR code**.

## 🔌 Browser filling

- On by default, also for vaults made before.
- Every start and unlock checks that Chrome, Edge, Brave and Firefox can reach MYLE, and repairs it when they cannot.
- **Browser filling** shows which browser connected and when, or what is missing, with **Repair**.
- The extension (1.2.0) says exactly why it cannot reach MYLE instead of "Browser filling is off" for everything.

## 🪟 Windows programs

- **Fill both** types the user name, Tab, then the password in one step.
- Programs that update into a new folder (Discord, Slack) stay linked, and Store apps are recognised.
- A program running as administrator gets Copy buttons, since Windows does not let MYLE type into it.
- A program with no login yet: **New login for it** or **Link a login…**; the login editor has **Browse…** for the program.
- When another program holds Ctrl+Shift+L, MYLE uses Ctrl+Alt+Shift+L.

## 📐 Password Manager layout

- The page fills the window: only the list and the login scroll, and more logins show on a 1080p screen.
- The login editor uses two columns where there is room, with Save always in sight.

## ⚠️ Good to know

- Update MYLE on every PC that shares your vault: an older version that edits a login drops its 2FA key and passkeys.
- Loaded the extension unpacked? Press reload on it in `chrome://extensions` or `edge://extensions` to get 1.2.0.

## 📦 Install or update

Download **MYLE.exe** from this release or use the download button above. Existing installations can use MYLE's built-in updater.

**Requirements:** Windows 10 or 11, x64. Start Menu customization requires a supported Windows 11 build. The setup installs Microsoft's WebView2 Runtime if it is missing.
