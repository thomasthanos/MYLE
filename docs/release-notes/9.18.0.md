### New
- Added a Software Health section to System Cleaner with eight scans:
  - Uninstallation leftovers: folders in AppData, ProgramData and Program Files of software that is no longer installed (checked against the Uninstall registry, AppX packages, services and running programs, with a confidence score), plus orphaned Uninstall entries.
  - Broken uninstalls: programs whose uninstaller or install folder is gone, with Force Clean.
  - Redundant files: caches, crash dumps and logs of known apps.
  - Software hibernation: startup entries, the Startup folder, automatic third-party services and busy background processes.
  - Software permissions: apps allowed to use the camera, microphone, location or run in the background.
  - Disturbing notifications: Windows app notifications and Chrome, Edge and Brave site notifications; Firefox can block new requests.
  - Installation files: old setup files in Temp and Downloads (same 7-day rule).
  - Suspicious software & extensions: side-loaded or developer-mode browser extensions, unsigned startup programs and scheduled tasks.
- Every change is previewed first and recorded in a Restore list: files go to the Recycle Bin, registry entries are exported to a .reg backup before removal, and switches can be turned back.

### Improved
- Windows, Microsoft packages, drivers, hardware vendors and MYLE itself are never offered for any change.
