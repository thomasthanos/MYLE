### New
- **MYLE 10:** the Windows app, MYLE Passwords for Android and iPhone, and the browser extension now share one version number, 10.0.0.
- **MYLE Passwords redesign:** the phone app now uses the same design as MYLE on Windows: the same theme, colours and backdrop. It adds 3D glass depth: lit card edges, layered soft shadows, a frosted top bar, raised buttons that press in when tapped, and short entrance animations (off when reduced motion is on).
- **Browser extension 10.0.0:**
  - Permissions are down to nativeMessaging, activeTab and storage; webNavigation is dropped.
  - Each passkey request runs on its own connection, so leaving the page cancels it instead of leaving it hanging.
  - A redesigned popup shows the live connection status.
  - Fields get a MYLE badge, filling works in React, Vue and web-component forms, and the 2FA code is offered after sign-in.
- **Install MYLE Passwords from the Chrome Web Store in one click** from Browser filling.
- **Project Backups:** changes are detected in the background, and one click backs up only the changed files.
- **Game Saves:**
  - Every restore can be undone, and undo loses nothing.
  - Restores find a Documents folder that OneDrive has moved.
  - More launchers and save folders are detected.
  - The schedule waits for a game to close instead of skipping, and keeps its hour.
- **Release Hub:** safe merge before a release, accurate CI tracking, and runs that can be resumed. The Release tab fits the default window without a scroll bar.

### Fixed
- **Extension:**
  - A copy left open in tabs after an update no longer throws errors.
  - Passkey requests respect the page's timeout and fall back to the browser's own passkeys.
  - "Try again" no longer signs in twice.
  - The save offer and passkey prompts no longer cancel each other.
  - Lookups are rate-limited per tab.
  - The generated password is no longer kept in session storage.
- **Browser bridge:** it keeps listening and survives restarts, and Windows Hello closes when cancelled.
- **Delete all passwords dialog:** a clean layout with the backup button on its own row and a full-width "Also delete passkeys" option with its warning below, so nothing overlaps.
- **SideStore source:** `docs/sidestore.json` now updates itself on every release (version, date, download link, size).
