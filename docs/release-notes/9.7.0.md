## ✨ Highlights

| | What's new |
|---|---|
| 🧭 **A project view that says what's next** | When nothing is changed: the commits since the last release and one-click Build, Release, Open folder and Open on GitHub. |
| ⚙️ **A compact settings window** | One line per AI provider with its status, drag to reorder, open a line to edit its key. |

## 🚀 GitHub Releases

- **Header**: the project's name, version (click for every version file), GitHub repository, folder (click to open it) and **last release**, with refresh and more actions beside them. Branch, changes and the last CI run share one strip below.
- **Nothing to commit?** The Changes tab now shows the commits since the last release (the ones not pushed yet are marked, each opens on GitHub) and the next steps: Pull or Push when needed, **Build**, **Release N commits**, **Open folder**, **Open on GitHub**. The diff pane appears only when there are changes.
- **Projects list**: a status dot per project (changes, commits to pull or push, unreleased commits), what it is built with and when it was last released; **Add another project** at the end.
- **Keyboard**: **Alt+1–4** switch between Changes, Build, Release and Releases, **Alt+R** refreshes, **/** searches.
- The note about projects brought over from Github-Build-Release now goes away for good with **Got it**.
- The page fits MYLE's default window size and makes use of a wider one.

## ⚙️ Settings

- **AI**: one compact line per provider showing **Not set**, **Key …ab12 ✓**, **Limit reached** or **Off**; the first ready one is marked **Used first**. Drag a line by its handle (or use the arrow keys) to change the order. Open a line to paste a key: **Check & save** lights up only when there is something to check.
- **GitHub account**: the connected account, how it is signed in and its scopes at a glance, or three short steps to connect.
- The privacy notes are one short line: keys are checked, kept encrypted for your Windows account and never shown again.

## 🔒 Owner-only pages

- **GitHub Releases** and **Project Backups** are now shown only when MYLE is signed in with the owner's Discord account. Everyone else, signed in or not, no longer sees them, and MYLE refuses their actions.
- MYLE checks the account with the sign-in server, not on the page, and remembers the answer for this Windows account (30 days offline).
- Signing out hides both pages at once and stops their builds, releases and backups.
