# MYLE 9.18.4 — Unified Enhancements

A more focused System Cleaner, safer software cleanup and clearer app permissions. This Windows release brings the latest fixes together with the password, update, appearance and productivity improvements previously collected in **MYLE Unified Enhancements**.

## New in 9.18.4

### A clearer System Cleaner

- Separate **Cleanup** and **Software Health** tabs make routine file cleanup and app management easier to navigate.
- Compact category cards show available space, selected space and the last cleanup. Results distinguish files removed, files still in use and files requiring administrator approval.
- Downloads details now open inside their category. The existing protection for documents and recent files, permanent deletion confirmation, locked-file handling and post-cleanup measurement remain in place.
- Navy surfaces, subtle glass depth, colored icons and responsive layouts make controls easier to read in both appearances and across window sizes.

### Software Health that works in batches

- Browse cleanup categories and app controls from a single workspace, with search by app or path, recommendation and failure filters, and sorting by name or size.
- Select recommended items or all filtered results without opening individual categories. Selections across filters and pages remain included in the total.
- Review all cleanup selections together, grouped by action, before applying them. App controls show how many selected items support each action.
- Successful items are deselected; failed items stay available for **Retry failed**. Affected categories and change history refresh after the operation.
- Pagination returns to the start of the results and restores keyboard focus when switching pages.

### More reliable detection and recovery

- Old or unrecognized folders are no longer reported as leftovers solely because of their age or an absent name match. Folder findings require a matching registered installation path and a verified missing uninstaller, while active-app, executable and shortcut evidence protects existing software.
- Detection includes 32-bit uninstall records, installation paths, display icons and executable search paths. Unreadable targets remain uncertain rather than being treated as missing.
- Folder cleanup uses the Windows Recycle Bin. Registry cleanup creates a backup first. Broken-entry cleanup removes only the entry by default; **Force clean** remains an explicit choice.
- Stable finding IDs retain selections across scans. Batch processing avoids duplicate targets and overlapping changes, and prevents concurrent scans, changes and restores from conflicting.
- App permissions show friendly application names, recognizable capability labels and clear **Block access / Allow access** actions. Technical IDs and paths remain available in Details.
- Game Saves migrates legacy missing-cover cache markers so older cache files do not cause unnecessary cover requests.

## Included from MYLE Unified Enhancements

- **Passwords and passkeys:** a configurable passphrase generator, quick-copy actions, improved search and filters, entry timestamps, keyboard shortcuts, cancellable verification, and the browser bridge's start/unlock-and-continue flow. MYLE can refresh its local unpacked extension copy after updates.
- **Updates and Spotify:** clearer update progress and failure handling, smoother handover to the new app window, repaired Spicetify update and installed-version checks, simpler completed-state actions, and automatic Spotify opening after successful setup.
- **Appearance and settings:** refined navy and charcoal surfaces, lightly raised glass controls, refreshed sidebar icons, searchable settings and guided Windows Optimization profiles with reversible changes.
- **Release Hub and backups:** merge-before-release controls, Windows-only or full build choices, live Actions monitoring and cancellation, resumable release work, and Project Backups change detection with one-click backup of changed projects.
- **What's New:** an update summary available after installation and from Settings, including versions missed between updates.
