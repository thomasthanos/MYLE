### Improved
- **SideStore** now shows what's new for each version (taken from these release notes) instead of "nil".
- **Welcome screen (phone)** always fits on one screen, without scrolling or bouncing, even on small iPhones.
- **Notifications (phone)** appear as a floating glass card above the home indicator instead of under the status bar and Dynamic Island.
- **Sign-in prompt:** MYLE can now start sign-in on its own address (for example login.thomast.uk), so iOS asks to use "thomast.uk" instead of the Supabase project address. This takes effect once that address is set up.

### Fixed
- **Discord sign-in (iPhone)** opens in a private sheet without Safari's cookies, so Discord no longer triggers "Passkey Updated: discord.com changed the username…" on every sign-in. Google sign-in still uses Safari's.
