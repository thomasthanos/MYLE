# MYLE 10.0.3

- **Vivaldi browser filling.** MYLE Passwords now accepts Vivaldi, using the existing Chrome Web Store extension. Browser setup includes Vivaldi and its extension-page shortcut.
- **Project backup reminders.** Every three days, MYLE checks all saved projects for changes and reminds you about projects that need a backup. The deadline survives restarting, and overdue checks run the next time MYLE opens. This only checks and notifies; backups are created when you choose.
- **Automatic Game Saves backups.** Missed daily or weekly backups catch up after sleep, sign-in or MYLE startup. Your selected day and time are respected, newly enabled schedules do not run earlier slots, and daylight-saving changes do not cause duplicate backups.
- **Extension downloads.** The release includes Chrome/Edge/Brave/Vivaldi and Firefox extension ZIPs, alongside the Windows installer.
