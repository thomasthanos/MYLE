# MYLE 12.0.4

- **Tidier AppData.** MYLE moves internal settings and cleanup records into a hidden folder. Software Health keeps its backup paths and hides its folder. Game Saves and the password vault stay in place.
- **Wand Enhancer.** The Creative Hub shows the version and any available update. MYLE removes its Wand Enhancer executable when it fully exits and retries any leftover copy on the next launch.
- **Windows integration.** MYLE resolves system tools through Windows, keeps installer extras hidden across updates, and improves certificate trust setup.
- **Interface.** The Steam sign-in window is easier to follow, Steam covers preload, and notifications stay visible above dialogs.
