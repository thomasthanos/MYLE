### New  
- Added a **Relocate Projects** button to the Project Backups page, opening a new modal for scanning drives and updating project folder paths.  
- Introduced a full‑screen **Relocate Modal** where users can:  
  - Scan selected drives or custom folders for candidate project locations.  
  - View candidate folders with detected Git remote and package information.  
  - Replace old source paths with new ones to relocate projects in bulk.  
- Backend commands added to support:  
  - Scanning folders for relocation candidates.  
  - Performing the actual project relocation based on user selections.  
- New API endpoints:  
  - `scanCandidates(root, maxDepth)` – returns a list of possible project folders.  
  - `relocateProjects(replacements)` – applies path changes to selected projects.  
  - `getDrives()` – provides information about available drives (letter, label, filesystem, space).  

### Improved  
- Project Backups UI now disables interactions while the relocation modal is open, preventing accidental actions.  
- Fixed handling of UTF‑8 BOM in settings files to avoid parsing errors.  

### Fixed  
- Minor UI bugs: corrected key handling and inert state logic to work with the new relocation modal.
