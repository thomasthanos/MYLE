# MYLE 10.0.5

- **Android credential provider.** On Android 14+, enable MYLE in Android's credential-provider settings to create and use passkeys or save and select passwords. The existing encrypted vault is shared with the MYLE app; no plaintext credential mirror is created.
- **Android Autofill and TOTP.** Choose MYLE as the autofill service to select a login and fill requested username, password and saved TOTP fields. Filling requires Android 8+; protected saving and browser HTTPS filling require Android 9+.
- **Protection before filling.** Verify with the master password or enable fingerprint for filling in Account. Fingerprint uses a per-operation Android Keystore CryptoObject; the master password remains available. Temporary authorization is bound to the vault and destination and expires after 90 seconds.
- **Website compatibility.** Unsupported authenticator requirements and extensions stay with the browser. Related-origin requests no longer get blocked by MYLE's desktop wrapper. Frame requests preserve browser permission and ancestor boundaries.
- **Verification.** Protocol fixtures are independently verified with SimpleWebAuthn, including Android native origins, browser client-data hashes, related origins and HTTPS ports. Altered challenge, origin, RP ID, signature and missing required user verification are rejected.

Enable Android filling from **Account → Use MYLE in other apps**. Chrome may also require **Autofill using another service** in its settings. Device/OEM behavior and real signed-in website flows require testing on the intended phone; this release does not guarantee every site's attestation, extension, UI naming or browser requirements. Provider names remain controlled by each website.
