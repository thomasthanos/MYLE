# MYLE 12.0.0

A major release: new things in Install Apps and the System Cleaner, and a full security and stability review of MYLE on Windows and MYLE Passwords on Android and iPhone. MYLE Passwords jumps to 12.0.0 with it, so every app now has the same version.

### New
- **Install Apps › Updates** lists every update winget reports, including apps with an unknown version or that aren't in MYLE's catalogue, with **Check all updates** and its own selection. Apps get their own icons and clearer categories. Updating apps now lives here only; System Maintenance no longer has a winget step.
- **System Cleaner as administrator:** relaunch MYLE as administrator from the System Cleaner, on the same page, to clean system folders. When MYLE already runs as administrator, scans include system folders without asking again. The cleaner remembers the tab you were on.
- **Cleanup results:** a cleanup shows progress and then what was freed and which files were in use, with an optional sound when it finishes. Downloads is handled more carefully.
- **BetterDiscord** can patch and unpatch Discord PTB too.
- **Firefox:** the browser extension can be installed from Firefox Add-ons, and the browser setup dialog says more clearly what is installed and what to do next.
- **A new splash screen** and a loading indicator while a page opens.

### Security
- **Administrator helpers:** their connection to MYLE is open only to your account, administrators and the system. When you approve a request for a different account, that approval covers one action, not half an hour of them. After a live update no helper starts until MYLE restarts.
- **Programs started as administrator** receive their arguments intact, even with spaces in a path, and a declined UAC prompt is told apart from a program Windows could not start.
- **Passkeys:** a web page can no longer start MYLE, bring it forward or ask for Windows Hello by itself; it needs your click. A passkey's private key never leaves the vault.
- **Passwords:** master passwords, recovery codes and the export password are wiped from memory once used. A copied password is cleared when the vault locks and when MYLE closes. Filling a Windows program never types the password into a field that shows it.
- **Sync:** two PCs saving settings at once no longer overwrite each other, and a login changed on two devices is decided by times sealed inside the vault, which the server can't change.
- **GitHub Releases:** files holding secrets (`.env`, keys, certificates) and anything shaped like a token are left out of what an AI provider receives, and background fetches never run a repository's hooks.
- **Disk Analyzer and cleanups** refuse an item that became a link after the scan. Spotify Hub's protected leftovers are removed the same safe way.
- **Disk Analyzer** warns before sending something inside OneDrive, Dropbox, iCloud or another synced folder to the Recycle Bin, since that also deletes it from the cloud and your other devices.

### Improved
- **A crash in one action no longer closes MYLE.** Only that action stops, and the details go to `internal\crash.log` in MYLE's local data folder.
- **Starting MYLE while it's already running** just brings the open copy forward and leaves its data alone. After an update that couldn't hand over, there is still only one MYLE.
- **Faster:** searching the vault, the GitHub Releases build log, the Online-only and cleaner scans, and file diffs in Project Backups. Long file and tool work no longer holds up the rest of the app.
- **Hung tools stop:** winget searches, `spicetify`, `gh` and the custom apps' tools time out. Cancel works during installs and release uploads.
- **The window opens at the right size** at high display scaling instead of partly under the taskbar.
- **Auto Clicker** clicks as often as set for intervals under 16 ms.
- **Closing MYLE** no longer waits on locked download leftovers.
- **Start with Windows** uses the Startup folder wherever Windows keeps it, and uninstalling with "remove data" also removes the download and Spotify Hub staging folder.

### Fixed
- **Game Saves:** a game that keeps its saves in the registry gets its registry values back too, when a restore fails part-way or is undone.
- **Project Backups:** a file that disappears during a backup is skipped instead of failing it, and a tracked build folder in a repository with a split git index is no longer left out.
- **Setup:** only MYLE's own programs in the install folder are closed, never other programs kept there, and a failed install puts the previous version back.
- **Steam:** a price with a thousands separator (1.234) is no longer listed as cents, idling asks for at most the 32 games Steam runs at once, and the Steam Guard count shows what is really waiting.
- **Windows Optimization:** its tabs no longer run changes at the same time, and reloading the page during a debloat or Spotify Hub run no longer lets a second one start. Showing Start's Recommended section again restores only what hiding it changed.
- **Clicks and answers:** a second click on Install, an older answer arriving late, or a background check under an open dialog no longer causes a double action or a wrong result.

### MYLE Passwords (Android and iPhone)
- **A private clipboard:** a copied password stays out of keyboard history and previews on Android and stays on this iPhone (never on a Mac or iPad through Universal Clipboard). It is emptied after 30 seconds, also when the app was in the background.
- **Android:** a fingerprint or face added after quick unlock was turned on turns it off and says why, instead of failing on every open. Updates install only from MYLE's own downloads, over https and with a checksum.
- **Sign-in:** a link from another app can no longer disturb a sign-in that is waiting, and on iPhone a sign-in sheet closed early no longer leaves the sign-in waiting for good.
- **The vault locks** when you leave with the back button, and the QR scanner stops when it locks.
- **Signing out** works even when the phone's key can't be removed, and the key left behind opens nothing.

This release includes the Windows installer, the Android APK and the iOS IPA.
