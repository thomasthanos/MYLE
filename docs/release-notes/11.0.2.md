# MYLE 11.0.2

### Security
- **Updates:** an update installs only when it carries MYLE's own signature and comes from MYLE's download server or MYLE's GitHub releases.
- **Password vault:** a master password changed on another device is taken in only when it was made with this vault's key, and the vault's key settings are checked before they are used, from this PC, a backup or your account.
- **Browser filling:** a login saved for an IP address (a router, a NAS) is offered only on that address, never on another one that happens to end the same way.

### Fixed
- **Project Backups:** a file or folder whose name ends in a Greek letter no longer closes MYLE. A restore now stops with a message instead of quietly putting back an older state when part of the latest backup can't be read (an online-only cloud file, say), and the next backup is then a full one.
- **System Cleaner:** Software Health moves items to the Recycle Bin only. Anything the bin can't take (too large, or a drive without a bin) stays where it is and is reported, instead of being deleted for good.
- **System Maintenance:** Check Disk starts again.
- **Password Manager:** a login with the same website twice no longer stops the page; the repeated address is dropped when it is saved. An entry too large to sync is refused with a reason, and no longer holds up the rest of the sync.
- **Password Manager:** the vault locks after the chosen idle time even when the PC slept in between.
- **Signing out** on this PC no longer signs you out of MYLE Passwords on your phone.
- **GitHub Releases:** a failed workflow that reports the same error twice no longer stops the page.
- **Cleaning as administrator** no longer stops on deeply nested temporary folders.
- **Game Saves:** a scan no longer stops on a save folder placed directly under `Users`.
- **Creative Suite** never replaces a file you already have in Downloads.
- **Setup:** the installer checks its own files before putting them in place, and leaves the previous version untouched when they are damaged.
