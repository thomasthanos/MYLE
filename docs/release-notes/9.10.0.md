## ✨ Highlights

| 🔄 **Seamless updates** | After an update installs, MYLE no longer disappears for a few seconds. It stays open until the new version's window is on screen. |

## 🔄 Updates

- **No more blank moment:** MYLE waited for "a window" of the new version, and counted a hidden helper window that Windows starts right away. So the old version closed while the new one was still loading. Now it waits until the new version's window is really on screen.
- If the new version closes before its window opens, the old one stays open and tells you, instead of leaving nothing on screen.
- When the setup window is used (if the quick update can't run), it also waits for the new version's window before it closes. It closes sooner after a successful update, and the new version skips a second update check.
- **Settings → Check for updates** now shows **Opening v…** while the new version starts.
- MYLE keeps a short `update.log` in its data folder: versions, results and timings only. It helps explain an update that didn't go smoothly.

## 🧭 Sidebar

- Pages are grouped and reordered: **Install Apps**, **Creative Suite** and **Spotify Hub**, then **Password Manager** and **Game Saves**, then **Windows Optimization**, **System Cleaner** and **System Maintenance**.
- Pages only the owner can see (**Project Backups**, **GitHub Releases**) are in their own **Owner** group. They have a small shield and a soft gold accent, and their tooltip says they are visible only to the owner account.
- Tooltips show each page's name, a short description and its shortcut. They appear at once when the sidebar is collapsed, and after a short pause when it isn't.
- **Shortcuts:** **Ctrl+1** to **Ctrl+9** open the pages in sidebar order, **Ctrl+,** opens Settings, and **Ctrl+B** still collapses the sidebar.
- **Keyboard:** the arrow keys, **Home** and **End** move through the sidebar, and the focused item has a clear ring. The current page is easier to spot.
- On a short window, the page list scrolls, and Settings and the collapse button stay where they are.
- The owner-only pages now load the first time they are opened (in the background for the owner). Everyone else's MYLE starts with about 30% less code to load.

## 🔒 Security

- **Updates:** MYLE installs only the exact file (address, size and SHA-256) its own update check found. The window can no longer ask it to run something else.
- **Web view:** stricter content rules (no plugins, frames, form posts or base-URL changes). Only the main window can open web links.
- **Windows tools:** PowerShell, Task Scheduler, taskkill, icacls, cmd and Explorer are always started from Windows' own folder, never from a copy that ended up next to MYLE.
- **GitHub Releases:** your GitHub token is only sent to GitHub's own upload address.
- An updated build tool fixes a reported issue (`source-map-js`). It doesn't ship in the app.
